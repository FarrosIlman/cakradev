# CakraDev — Jasa Pembuatan Sistem Informasi & Aplikasi Custom

Website resmi **CakraDev**, studio software engineering yang melayani jasa pembuatan sistem informasi manajemen (SIM), sistem rekam medis elektronik klinik (EMR), sistem inventaris pergudangan, POS kasir toko, hingga aplikasi mobile custom untuk bisnis dan instansi di seluruh Indonesia.

---

## ⚡ Layanan & Keunggulan CakraDev

- **Sistem Informasi Manajemen & ERP Kustom**: Modul gudang, kasir POS, akuntansi keuangan, absensi karyawan, hingga dashboard analitik real-time.
- **Sistem Rekam Medis Elektronik (EMR Klinik)**: Standar diagnosa medis terstruktur, antrean pasien online, kasir obat farmasi, dan rekap resep.
- **Aplikasi Web Enterprise & Mobile Android**: Dibangun dengan teknologi modern (Next.js, React, Kotlin, Laravel) yang cepat dan responsif.
- **Integrasi Payment Gateway & WhatsApp**: Terima pembayaran otomatis via QRIS / Bank Transfer dan kirim invoice langsung ke WhatsApp pelanggan.
- **100% Hak Milik Source Code**: Kode program diserahkan sepenuhnya ke klien tanpa keterikatan lisensi per-user bulanan.
- **Garansi & Pendampingan Penuh**: Garansi perbaikan bug dan pelatihan penggunaan langsung untuk staf Anda.

---

## 📦 Menjalankan Secara Lokal

1. **Install dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan server development**:
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

3. **Build Produksi**:
   ```bash
   npm run build
   ```
